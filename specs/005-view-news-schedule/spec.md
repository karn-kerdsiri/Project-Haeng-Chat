# Feature: ดูข่าวสารและตารางเวลาประจำเทอม (View News and Term Schedule)
Spec ID: SPEC-NWS-005 | Source: Use Case Specification UC-05 ดูข่าวสารและตารางเวลาประจำเทอม | Use case: UC-05
Owner: ทีม B | Status: Draft v1 | Updated: 2569-10-21

## Goal
นักศึกษาดูข่าวสารและตารางเวลาประจำเทอมที่เผยแพร่ล่าสุดได้
เพื่อทราบกำหนดการและช่วงเวลาที่เกี่ยวข้องกับการส่งข้อมูลและการตรวจสอบคุณสมบัติ

## Scope
### In scope
- IN-NWS-01 แสดงรายการข่าวสารและตารางเวลาที่เผยแพร่แล้ว            <- UC-05 ขั้น 1
- IN-NWS-02 เลือกหัวข้อข่าวสารหรือตารางเวลาที่ต้องการดู              <- UC-05 ขั้น 2
- IN-NWS-03 แสดงรายละเอียดและช่วงเวลาที่เกี่ยวข้องของหัวข้อที่เลือก    <- UC-05 ขั้น 3
- IN-NWS-04 แจ้งกรณีไม่มีประกาศ และกรณีตารางเวลายังไม่เผยแพร่        <- UC-05 alt 1-2
### Out of scope
- OUT-NWS-01 การจัดทำและแก้ไขตารางเวลาประจำเทอม - เป็นของ UC-15
- OUT-NWS-02 การสร้างและเผยแพร่การแจ้งเตือนในระบบ - เป็นของ UC-17
- OUT-NWS-03 การสร้างและแก้ไขเนื้อหาข่าวสาร - ไม่มี use case ใดใน diagram ครอบคลุม (ดู OQ-NWS-01)
- OUT-NWS-04 การเปิด/ปิดแบบฟอร์มตามช่วงเวลา - เป็นของ ข้อ 6 ซึ่งบังคับใช้ใน UC-01, UC-02 และ UC-15 spec นี้แสดงเฉพาะข้อมูลช่วงเวลา
- OUT-NWS-05 การส่งข่าวสารทางอีเมลหรือช่องทางภายนอก - UC-05 ไม่ระบุ

## Constraints
- IF-WEB-01 ทุกหน้าจอของฟีเจอร์นี้ต้องทำงานบนเบราว์เซอร์โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม   <- ข้อ 13
- IF-TECH-01 ส่วนหน้าจอพัฒนาด้วย React และข้อมูลข่าวสาร/ตารางเวลาเก็บในฐานข้อมูล PostgreSQL   <- ข้อ 19
- IF-AUTH-01 หน้าที่ต้องยืนยันตัวตนต้องใช้บัญชีเดียวกับระบบของมหาวิทยาลัย   <- ข้อ 12 (UC-05 Precondition ไม่ชัดว่าต้องล็อกอินหรือไม่ ดู OQ-NWS-02)
- IF-SCHED-01 ข้อมูลตารางเวลาที่แสดงต้องเป็นชุดเดียวกับที่ระบบใช้ควบคุมการเปิด/ปิดแบบฟอร์ม   <- ข้อ 6
- CON-NWS-01 ระบบต้องแสดงเฉพาะข่าวสารและตารางเวลาที่เผยแพร่แล้ว   <- UC-05 Postcondition, alt 2

## Data Rules
- DR-NWS-01 ข้อมูลที่แสดงต่อ 1 ข่าวสาร: หัวข้อ รายละเอียด และช่วงเวลาที่เกี่ยวข้อง (ถ้ามี)   <- UC-05 ขั้น 1-3
- DR-NWS-02 ข้อมูลที่แสดงต่อ 1 รายการในตารางเวลา: ชื่อกิจกรรม วันเริ่ม และวันสิ้นสุด   <- UC-15 ขั้น 2 (รูปแบบที่แสดงรอยืนยัน ดู OQ-NWS-03)
- DR-NWS-03 รายการที่แสดงต้องเรียงให้เห็นประกาศล่าสุดก่อน   <- UC-05 Acceptance Criteria (เกณฑ์การเรียงรอยืนยัน ดู OQ-NWS-04)

## Requirements
- FR-NWS-01 ระบบต้องแสดงรายการข่าวสารและตารางเวลาที่เผยแพร่แล้วตาม CON-NWS-01 และ DR-NWS-03   <- UC-05 ขั้น 1
- FR-NWS-02 ระบบต้องให้ผู้ใช้เลือกหัวข้อที่ต้องการดูรายละเอียด   <- UC-05 ขั้น 2
- FR-NWS-03 ระบบต้องแสดงรายละเอียดและช่วงเวลาที่เกี่ยวข้องตาม DR-NWS-01 และ DR-NWS-02   <- UC-05 ขั้น 3
- FR-NWS-04 เมื่อไม่มีข่าวสารที่เผยแพร่ ระบบต้องแสดงข้อความว่าไม่มีประกาศ   <- UC-05 alt 1
- FR-NWS-05 เมื่อตารางเวลาของภาคการศึกษานั้นยังไม่เผยแพร่ ระบบต้องแจ้งว่ายังไม่มีข้อมูล และต้องไม่แสดงร่างตารางเวลา   <- UC-05 alt 2
- FR-NWS-06 เมื่อเรียกข้อมูลไม่สำเร็จ ระบบต้องแสดงข้อผิดพลาดและให้ลองใหม่   <- UC-05 Exception
- FR-NWS-07 ข้อมูลช่วงเวลาที่แสดงต้องตรงกับข้อมูลที่ระบบใช้ควบคุมการเปิด/ปิดแบบฟอร์มตาม IF-SCHED-01   <- ข้อ 6

## Quality Requirements
- NFR-NWS-01 [Usability] ข้อความทั้งหมดรวมถึงข้อความแจ้งข้อผิดพลาดต้องเป็นภาษาไทย   <- ข้อ 10
- NFR-NWS-02 [Usability] ทุกหน้าจอของฟีเจอร์นี้ต้องใช้งานได้บนจอโทรศัพท์มือถือ โดยไม่มีการเลื่อนแนวนอนที่ความกว้างจอตั้งแต่ 360 px   <- ข้อ 11 (ค่า 360 px เป็นค่าที่เสนอไว้ ดู ASM-NWS-01)
- NFR-NWS-03 [Availability] หน้าข่าวสารและตารางเวลาต้องพร้อมใช้งานไม่น้อยกว่า 99% ต่อเดือน   <- ค่าที่เสนอไว้ ดู ASM-NWS-01
- NFR-NWS-04 [Performance] หน้ารายการข่าวสาร: เวลาตอบสนอง p95 <= 2 วินาที   <- ค่าที่เสนอไว้ ดู ASM-NWS-01
- NFR-NWS-05 [Security] ถ้าหน้านี้ต้องยืนยันตัวตน ระบบต้องตัดการเชื่อมต่ออัตโนมัติเมื่อไม่มีการใช้งานเกิน 30 นาที   <- ข้อ 9 (ขึ้นกับคำตอบของ OQ-NWS-02)

## Acceptance Criteria
- [ ] AC-NWS-01 (FR-NWS-01, FR-NWS-03, CON-NWS-01)
      Given มีข่าวสารและตารางเวลาที่เผยแพร่แล้ว
      When  เปิดเมนูข่าวสาร/ตารางเวลาประจำเทอม
      Then  ระบบแสดงรายการล่าสุด และเปิดดูรายละเอียดพร้อมช่วงเวลาที่เกี่ยวข้องได้
- [ ] AC-NWS-02 (FR-NWS-04)
      Given ไม่มีข่าวสารที่เผยแพร่
      When  เปิดเมนูข่าวสาร
      Then  ระบบแสดงข้อความว่าไม่มีประกาศ
- [ ] AC-NWS-03 (FR-NWS-05)
      Given ตารางเวลาของภาคการศึกษาปัจจุบันยังไม่เผยแพร่
      When  เปิดหน้าตารางเวลา
      Then  ระบบแจ้งว่ายังไม่มีข้อมูล และไม่แสดงรายการใด
- [ ] AC-NWS-04 (FR-NWS-06, NFR-NWS-01)
      Given แหล่งข้อมูลข่าวสารไม่พร้อมใช้งาน
      When  เปิดเมนูข่าวสาร
      Then  ระบบแสดงข้อความผิดพลาดภาษาไทยพร้อมให้ลองใหม่
- [ ] AC-NWS-05 (FR-NWS-07, IF-SCHED-01)
      Given ตารางเวลาระบุช่วงเปิดรับข้อมูลวันที่ X ถึง Y
      When  เทียบข้อมูลที่หน้าตารางเวลาแสดงกับเงื่อนไขที่ระบบใช้เปิด/ปิดแบบฟอร์ม
      Then  ช่วงเวลาต้องตรงกันทั้งสองที่
- [ ] AC-NWS-06 (NFR-NWS-02)
      Given เปิดหน้าข่าวสารบนจอกว้าง 360 px
      When  แสดงผลเสร็จ
      Then  เนื้อหาอ่านได้ครบและไม่มีการเลื่อนแนวนอน

## Assumptions & Open Questions
- ASM-NWS-01 UC-05 ระบุ NFR เป็นหมวด (Usability, Availability) ค่าตัวเลขใน NFR-NWS-02, NFR-NWS-03 และ NFR-NWS-04 จึงเป็นค่าที่เสนอไว้เพื่อให้ทดสอบได้ รอทีมยืนยัน
- ASM-NWS-02 ข้อ 19 ระบุ React + PostgreSQL spec นี้จึงยึดข้อ 19 ซึ่งต่างจาก plan.md ของ specs/001-Enter-educational-information ที่ใช้ Supabase ทีมต้องตัดสินและปรับ 001 ให้ตรงกัน
- ASM-NWS-03 ตารางเวลาที่หน้านี้แสดงคือตารางเวลาที่เจ้าหน้าที่จัดทำใน UC-15 ชุดเดียวกัน
- OQ-NWS-01 ข่าวสารถูกสร้างและเผยแพร่โดย use case ใด diagram ไม่มี use case จัดการเนื้อหาข่าวสาร และรายการความต้องการ 20 ข้อไม่ได้ระบุ
- OQ-NWS-02 UC-05 Precondition เขียนว่า "นักศึกษาเข้าสู่ระบบหรือเข้าถึงหน้าข่าวสารได้" หน้านี้เปิดให้ผู้ที่ยังไม่ล็อกอินเข้าดูได้หรือไม่ ซึ่งกระทบ IF-AUTH-01 และ NFR-NWS-05
- OQ-NWS-03 ตารางเวลาต้องแสดงในรูปแบบใด (ตารางรายกิจกรรม ปฏิทิน หรือรายการช่วงวัน) และต้องแสดงกี่ภาคการศึกษา
- OQ-NWS-04 "ล่าสุด" ใช้เกณฑ์วันที่เผยแพร่หรือวันที่แก้ไขครั้งสุดท้าย และต้องมีการปักหมุดประกาศสำคัญหรือไม่
- OQ-NWS-05 อาจารย์ที่ปรึกษาและเจ้าหน้าที่ใช้หน้านี้ด้วยหรือไม่ UC-05 ระบุ actor เป็นนักศึกษาเท่านั้น
