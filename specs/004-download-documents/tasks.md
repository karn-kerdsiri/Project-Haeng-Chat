# งานพัฒนา SPEC-DOC-004: ดาวน์โหลดเอกสารที่เกี่ยวข้อง

ที่มา: [spec.md](./spec.md) และ [plan.md](./plan.md)

รายการงานนี้แบ่งตามลำดับในแผน โดยอ้างอิง FR/AC/Constraint เดิมจากสเปก ส่วนที่ขึ้นกับ Open Questions ให้รอคำตอบก่อนกำหนดข้อมูลหรือเกณฑ์ทดสอบที่เกี่ยวข้อง

| ลำดับ | งาน | อ้างอิง | ทำหลังจาก | สถานะ |
|---|---|---|---|---|
| 1 | ตรวจ metadata และที่เก็บไฟล์ที่มีอยู่ โดยคงการอัปโหลด/แก้ไขเอกสารของเจ้าหน้าที่ไว้นอกขอบเขต | OUT-DOC-01, Q-01 | - | รอเริ่ม |

## งานที่ยังรอคำตอบจาก Open Questions

- **Q-01:** ข้อกำหนดที่อนุมัติแล้วและการปรับ use case สำหรับการอัปโหลด/แก้ไขเอกสารโดยเจ้าหน้าที่; ฟังก์ชันจัดการเอกสารยังอยู่นอกขอบเขตและไม่สร้าง API หรือ FR ใหม่.
- **Q-02:** ชื่อหมวดหมู่เอกสารและแหล่งกำหนดรายการหมวดหมู่; ยังไม่กำหนดชื่อหรือค่าเริ่มต้นแทนทีม.
- **Q-03:** ต้องมีเกณฑ์ตรวจรับเฉพาะสำหรับ NFR-DOC-05 และ NFR-DOC-06 หรือไม่; ยังไม่สร้าง AC ID ใหม่หรือเงื่อนไขทดสอบเพิ่มเติมโดยไม่ได้รับอนุมัติ.
