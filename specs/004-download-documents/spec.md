# Feature: ดาวน์โหลดเอกสารที่เกี่ยวข้อง (Download Related Documents)
Spec ID: SPEC-DOC-004 | Source: Use Case Specification UC-04 ดาวน์โหลดเอกสารที่เกี่ยวข้อง + รายการความต้องการของทีม ข้อ 5, ข้อ 15 | Use case: UC-04
Owner: ทีม B | Status: Draft v2 | Updated: 2569-11-13

## Goal
นักศึกษาที่เข้าสู่ระบบแล้ว เห็นรายการเอกสารแบบฟอร์มและเอกสารประกอบที่ใช้กรอกและทำโครงงาน
เลือกเอกสารจากหมวดหมู่ และดาวน์โหลดเอกสารนั้นได้ โดยระบบตรวจสอบสิทธิ์ก่อนส่งไฟล์ทุกครั้ง

## Scope
### In scope
- IN-DOC-01 แสดงรายการเอกสารที่นักศึกษามีสิทธิ์เข้าถึง แบ่งตามหมวดหมู่  <- UC-04 ขั้น 1
- IN-DOC-02 เลือกเอกสารที่ต้องการดาวน์โหลด                          <- UC-04 ขั้น 2
- IN-DOC-03 ตรวจสอบสิทธิ์ก่อนเริ่มดาวน์โหลด                         <- UC-04 ขั้น 3
- IN-DOC-04 ส่งไฟล์ให้ดาวน์โหลด                                    <- UC-04 ขั้น 4
- IN-DOC-05 แจ้งกรณีไม่มีเอกสาร ไม่มีสิทธิ์ และไฟล์ไม่พร้อมใช้งาน      <- UC-04 alt 1-2, Exception
### Out of scope
- OUT-DOC-01 การอัปโหลดและปรับปรุงเอกสารโดยเจ้าหน้าที่ - ยังไม่รวมในขอบเขตจนกว่าจะมี UC/FR ID ที่อนุมัติและปรับ use case ที่เกี่ยวข้อง (ดู Q-01)
- OUT-DOC-02 การเข้าสู่ระบบและยืนยันตัวตน - ถือว่าสำเร็จแล้ว (UC-04 Precondition, ข้อ 12)
- OUT-DOC-03 การลงนาม/รับรองเอกสาร - เป็นของ UC-11
- OUT-DOC-04 การเผยแพร่ผลการตรวจสอบ - เป็นของ UC-14
- OUT-DOC-05 การสร้างเอกสารจากข้อมูลในระบบ (เช่น ออกใบรับรองอัตโนมัติ) - UC-04 ไม่ระบุ

## Constraints
- IF-AUTH-01 ทุก request ของฟีเจอร์นี้ต้องมี session ที่ยืนยันตัวตนด้วยบัญชีเดียวกับระบบของมหาวิทยาลัย มิฉะนั้นตอบ HTTP 401   <- ข้อ 12
- IF-WEB-01 ทุกหน้าจอของฟีเจอร์นี้ต้องทำงานบนเบราว์เซอร์โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม   <- ข้อ 13
- IF-TECH-01 ส่วนหน้าจอพัฒนาด้วย React และข้อมูลรายการเอกสารเก็บในฐานข้อมูล PostgreSQL   <- ข้อ 19
- CON-FILE-01 ไฟล์เอกสารต้องเป็น PDF, JPG หรือ PNG ขนาดไม่เกิน 10 MB ต่อไฟล์   <- ข้อ 15
- CON-DOC-01 ระบบต้องตรวจสอบสิทธิ์ของผู้เรียกก่อนส่งไฟล์ทุกครั้ง ไม่ใช่ตรวจเฉพาะตอนแสดงรายการ   <- UC-04 ขั้น 3

## Data Rules
- DR-DOC-01 ข้อมูลที่แสดงต่อ 1 เอกสาร: ชื่อเอกสารและคำอธิบายว่าใช้ทำอะไร โดยจัดกลุ่มตามหมวดหมู่ (ชื่อหมวดหมู่รอยืนยัน ดู Q-02)
- DR-DOC-02 รายการที่แสดงต้องมีเฉพาะเอกสารที่เผยแพร่แล้ว โดยนักศึกษาที่เข้าสู่ระบบทุกคนเห็นชุดเอกสารเดียวกัน   <- UC-04 ขั้น 1, Precondition
- DR-DOC-03 เอกสารที่ไม่ตรงเงื่อนไข CON-FILE-01 ต้องไม่ถูกเผยแพร่ให้ดาวน์โหลด   <- ข้อ 15

## Requirements
- FR-DOC-01 ระบบต้องแสดงรายการเอกสารตาม DR-DOC-01 และ DR-DOC-02   <- UC-04 ขั้น 1
- FR-DOC-02 ระบบต้องให้นักศึกษาเลือกเอกสารหนึ่งรายการจากรายการเพื่อดาวน์โหลด   <- UC-04 ขั้น 2
- FR-DOC-03 ระบบต้องตรวจสอบสิทธิ์ตาม CON-DOC-01 ก่อนเริ่มส่งไฟล์   <- UC-04 ขั้น 3
- FR-DOC-04 เมื่อผ่านการตรวจสิทธิ์ ระบบต้องส่งไฟล์ให้ดาวน์โหลดได้   <- UC-04 ขั้น 4
- FR-DOC-05 เมื่อไม่มีเอกสารที่เผยแพร่ให้นักศึกษาเข้าถึงได้ ระบบต้องแสดงข้อความว่าไม่มีเอกสาร ไม่แสดงรายการว่าง ๆ โดยไม่มีคำอธิบาย   <- UC-04 alt 1
- FR-DOC-06 เมื่อนักศึกษาไม่มีสิทธิ์ในเอกสารที่ขอ ระบบต้องปฏิเสธการดาวน์โหลดด้วย HTTP 403 และไม่ส่งไฟล์   <- UC-04 alt 2
- FR-DOC-07 เมื่อไฟล์อ่านไม่ได้หรือหาไม่พบ ระบบต้องแจ้งข้อความภาษาไทยทั่วไปที่ระบุว่าไฟล์ไม่พร้อมให้ดาวน์โหลด และไม่ส่งไฟล์ที่ไม่สมบูรณ์   <- UC-04 Exception
- FR-DOC-08 ระบบต้องปฏิเสธการเรียกไฟล์โดยตรงที่ไม่ผ่านการตรวจสิทธิ์ตาม FR-DOC-03   <- CON-DOC-01

## Quality Requirements
- NFR-DOC-01 [Security] ระบบต้องตัดการเชื่อมต่อของบัญชีผู้ใช้อัตโนมัติ เมื่อไม่มีการใช้งานต่อเนื่องครบ 30 นาที   <- ข้อ 9
- NFR-DOC-02 [Security] ลิงก์ดาวน์โหลดต้องใช้ได้เฉพาะผู้ที่ผ่านการตรวจสิทธิ์ การเรียกโดยไม่มีสิทธิ์ต้องได้ HTTP 401 หรือ 403   <- UC-04 NFR (Security)
- NFR-DOC-03 [Availability] บริการดาวน์โหลดเอกสารต้องพร้อมใช้งานไม่น้อยกว่า 99% ต่อเดือนในช่วงเปิดรับข้อมูล   <- ข้อเสนอที่ทีมยืนยัน ดู ASM-DOC-01
- NFR-DOC-04 [Usability] ข้อความแจ้งข้อผิดพลาดต้องเป็นภาษาไทยและระบุสาเหตุ   <- ข้อ 10
- NFR-DOC-05 [Usability] ทุกหน้าจอของฟีเจอร์นี้ต้องใช้งานได้บนจอโทรศัพท์มือถือ โดยไม่มีการเลื่อนแนวนอนที่ความกว้างจอตั้งแต่ 360 px   <- ข้อ 11 (ข้อเสนอที่ทีมยืนยัน ดู ASM-DOC-01)
- NFR-DOC-06 [Performance] เริ่มส่งไฟล์ขนาด 10 MB ภายใน 3 วินาทีหลังกดดาวน์โหลด   <- ข้อเสนอที่ทีมยืนยัน ดู ASM-DOC-01

## Acceptance Criteria
- [ ] AC-DOC-01 (FR-DOC-03, FR-DOC-04)
      Given มีเอกสารเผยแพร่และนักศึกษามีสิทธิ์เข้าถึง
      When  เลือกเอกสารและกดดาวน์โหลด
      Then  ระบบส่งไฟล์ให้ดาวน์โหลดได้สำเร็จ
- [ ] AC-DOC-02 (FR-DOC-01, DR-DOC-01, DR-DOC-02)
      Given มีเอกสารเผยแพร่ 3 รายการ
      When  เปิดหน้ารายการเอกสาร
      Then  ระบบแสดงทั้ง 3 รายการพร้อมชื่อและคำอธิบาย แบ่งตามหมวดหมู่ โดยนักศึกษาทุกคนเห็นรายการชุดเดียวกัน
- [ ] AC-DOC-03 (FR-DOC-05)
      Given ไม่มีเอกสารที่นักศึกษาเข้าถึงได้
      When  เปิดหน้ารายการเอกสาร
      Then  ระบบแสดงข้อความว่าไม่มีเอกสาร
- [ ] AC-DOC-04 (FR-DOC-06, FR-DOC-08, NFR-DOC-02)
      Given เอกสาร X ยังไม่เผยแพร่และนักศึกษาไม่มีสิทธิ์เข้าถึง
      When  เรียกดาวน์โหลดเอกสาร X โดยตรง
      Then  ระบบตอบ HTTP 403 และไม่ส่งไฟล์
- [ ] AC-DOC-05 (FR-DOC-07, NFR-DOC-04)
      Given ไฟล์ของเอกสารที่เลือกอ่านไม่ได้หรือหาไม่พบ
      When  กดดาวน์โหลด
      Then  ระบบแจ้งข้อความภาษาไทยทั่วไปที่ระบุว่าไฟล์ไม่พร้อมให้ดาวน์โหลด และไม่ส่งไฟล์ที่ไม่สมบูรณ์
- [ ] AC-DOC-06 (CON-FILE-01, DR-DOC-03)
      Given มีไฟล์ที่ไม่ใช่ PDF/JPG/PNG หรือมีขนาดเกิน 10 MB
      When  ตรวจรายการเอกสารที่เผยแพร่
      Then  ไฟล์นั้นไม่ปรากฏให้ดาวน์โหลด
- [ ] AC-DOC-07 (NFR-DOC-01)
      Given ผู้ใช้ไม่มีการใช้งานต่อเนื่องครบ 30 นาที
      When  กดดาวน์โหลดเอกสาร
      Then  ระบบตัดการเชื่อมต่อและให้ยืนยันตัวตนใหม่

## Assumptions & Open Questions
- ASM-DOC-01 ทีมยืนยันข้อเสนอให้บริการพร้อมใช้งานไม่น้อยกว่า 99% ต่อเดือนในช่วงเปิดรับข้อมูล, รองรับหน้าจอตั้งแต่ 360 px โดยไม่มีการเลื่อนแนวนอน, เริ่มส่งไฟล์ 10 MB ภายใน 3 วินาที และตัด session เมื่อไม่มีการใช้งานครบ 30 นาที
- ASM-DOC-02 ข้อ 19 ระบุ React + PostgreSQL spec นี้จึงยึดข้อ 19 ซึ่งต่างจาก plan.md ของ specs/001-Enter-educational-information ที่ใช้ Supabase ทีมต้องตัดสินและปรับ 001 ให้ตรงกัน
- ASM-DOC-03 ข้อ 15 กำหนดไฟล์แนบไม่เกิน 10 MB ต่างจาก DR-EDU-06 ใน specs/001 ที่กำหนด 5 MB spec นี้ยึดข้อ 15 ตามที่ทีมสั่ง และทีมต้องปรับ 001 ให้ตรงกัน
- ASM-DOC-04 ทีมยืนยันว่าเอกสารในฟีเจอร์นี้หมายถึงแบบฟอร์มและเอกสารประกอบที่นักศึกษาใช้กรอกและทำโครงงาน ไม่ใช่ผลการศึกษาที่แคปจากหน้าเว็บมหาวิทยาลัย
- ASM-DOC-05 ทีมยืนยันให้นักศึกษาที่เข้าสู่ระบบทุกคนเห็นเอกสารที่เผยแพร่ชุดเดียวกัน และจัดเอกสารเป็นหมวดหมู่เพื่อให้นักศึกษาเลือกดาวน์โหลด
- ASM-DOC-06 ทีมยืนยันว่าต้องการให้เจ้าหน้าที่ทุกคนจัดการเอกสารได้ และหากรวมงานนี้ในขอบเขตภายหลัง ไฟล์ใหม่มีผลทันทีโดยไม่เก็บรุ่นเดิม; ขณะนี้ยังไม่รวมการจัดการดังกล่าวจนกว่าจะมี UC/FR ID ที่อนุมัติและปรับ use case ที่เกี่ยวข้อง
- ASM-DOC-07 ทีมยืนยันว่ารายการแสดงเฉพาะชื่อเอกสารและคำอธิบายการใช้งาน ไม่แสดงสถานะพร้อมใช้งาน; ไม่เก็บประวัติการดาวน์โหลด; และดาวน์โหลดได้ครั้งละหนึ่งเอกสาร
- ASM-DOC-08 ทีมยืนยันให้แจ้งข้อผิดพลาดด้วยข้อความภาษาไทยทั่วไปที่บอกสาเหตุในระดับผู้ใช้ เช่น “ไฟล์ไม่พร้อมให้ดาวน์โหลด”
- Q-01 ข้อกำหนดที่อนุมัติแล้วข้อใดจะครอบคลุมการอัปโหลดและปรับปรุงเอกสารโดยเจ้าหน้าที่ทุกคน และจะปรับ use case ที่เกี่ยวข้อง (เช่น UC-12) อย่างไร ก่อนนำงานนี้เข้าขอบเขต; ผู้ตอบ: ทีมเจ้าของ SRS/Use Case
- Q-02 หมวดหมู่เอกสารที่อนุมัติแล้วมีชื่อใดบ้าง และจะกำหนดรายการหมวดหมู่จากที่ใด; ผู้ตอบ: ทีมเจ้าของเอกสาร/ทีมเจ้าของ SRS
- Q-03 ต้องมีเกณฑ์ตรวจรับเฉพาะสำหรับ NFR-DOC-05 และ NFR-DOC-06 หรือไม่; หากต้องมี ให้ทีมอนุมัติ AC ID และเงื่อนไขทดสอบก่อนเพิ่ม เนื่องจากยังไม่มี AC ที่ครอบคลุมโดยตรง; ผู้ตอบ: ทีมเอง
