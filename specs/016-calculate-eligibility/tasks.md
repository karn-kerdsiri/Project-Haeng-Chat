## 7. หมายเหตุและข้อจำกัด

1. งานทั้งหมดต้องตรวจสอบย้อนกลับไปยัง FR, NFR, Constraint, Data Rule หรือ AC ที่ระบุไว้ใน Spec
2. ผลการคำนวณต้องมีเพียงผ่าน/ไม่ผ่านตามขอบเขตที่ทีมยืนยันแล้ว
3. การคำนวณต้องใช้ชุดเงื่อนไขที่ใช้งานอยู่จาก UC-12 ไม่กำหนดตัวเลข GPAX จำนวนหน่วยกิต หรือรายวิชาบังคับขึ้นเอง
4. ค่าระยะเวลาการคำนวณ 3 วินาทีเป็นค่าที่ระบุไว้ใน ASM-CAL-01 และ NFR-CAL-01
5. งานที่เกี่ยวข้องกับ OQ-CAL-03 และ OQ-CAL-05 ต้องรอคำตอบจากทีมก่อนกำหนดรายละเอียดเพิ่มเติม
6. เทคโนโลยีที่ไม่ได้ระบุใน Constraints เป็นการเลือกของทีม ไม่ใช่ข้อกำหนดจาก Spec
7. ไฟล์นี้เป็นรายการวางแผนงาน ยังไม่ใช่การเริ่มพัฒนาโค้ด
